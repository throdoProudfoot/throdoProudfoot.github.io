Release Notes — v6.0.1

v6.0.1 Release date · 2026-08-18 · Foundry VTT 14
Maintenance release
  • No data migration is associated with this release.
  • Foundry VTT v14 remains the supported platform.

A stability pass after v6.0.0

Version 6.0.1 is a corrective release focused on stabilizing the major changes introduced in v6.0.0, especially Foundry VTT v14 compatibility and the sheets rebuilt on ApplicationV2.

It restores a number of interactions that had become unreliable or inaccessible, prevents several cases where edited data could be lost or altered, and brings the diamond components used across the sheets under one consistent visual state model.

✦

What’s fixed

🛡️
Player-hero resources

Shadow Scars are editable again, and recovering Hope no longer resets the Community’s maximum Fellowship Points.

👁️
Community sheet

Eye Awareness respects Lore-master-only visibility, and long Connections lists can now be scrolled normally.

🧭
Journeys & Journey Logs

Small Companies can assign multiple journey roles to one Player-hero, and queued Item-sheet saves complete before a sheet closes.

🖼️
Sheet reliability

Item image editing and resizing are restored, while document portraits and tokens now display consistently across sheet types.

◆
Diamond consistency

Editable, read-only, and computed diamonds now use an explicit shared state contract and consistent design tokens.

🧪
Technical quality

Lint warnings were cleaned up and the Playwright regression suite was hardened around Foundry v14 interaction contracts.

✦

Interface polish

  • TOR2E heading styles are now scoped to the system UI and no longer override Foundry’s native headings.
  • The Load and Shadow meters on the Character Sheet have been reorganized for a clearer visual hierarchy.
  • Image display behavior is standardized across Actor and Item sheets.
  • Diamond components now communicate whether a value is editable, read-only, or computed through one shared visual language.
✦

How to upgrade

  1. Make sure you are running Foundry VTT v14.
  2. Install or update TOR2E to v6.0.1 from the package manager.
  3. Open your world normally. No v6.0.1 data migration is required.
  4. Report any remaining issue on the project’s GitLab issue tracker.
