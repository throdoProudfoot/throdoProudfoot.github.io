# TOR2E — vNext Announcement

A new TOR2E release is on the way, with a strong focus on **rules reliability, data persistence and confidence at the table**.

This update strengthens some of the most frequently used parts of the system:

- 🎲 more reliable rolls for **Weary**, **Miserable**, **Favoured / Ill-favoured**, **Hope**, **Inspired**, bonus and penalty dice;
- ◆ safer handling of **Active Effects**, so editable sheet values no longer risk applying an effect twice;
- 💾 stronger persistence across Characters, Adversaries, NPCs, Lore Actors, Communities and Items;
- ⚔️ better protection of weapon, Protection and skill-roll chat workflows;
- 🧭 safer world migrations when an upgrade fails;
- 🖥️ several sheet and interface fixes for Foundry VTT 14.

Behind the scenes, the automated regression suite has also grown significantly. Complete Foundry workflows now protect many more TOR2E rules and interactions before a release ships.

The goal of this release is simple: **what you see, save and roll should behave predictably every time.**

Full release notes and changelog will be published with the final version number and release date.
