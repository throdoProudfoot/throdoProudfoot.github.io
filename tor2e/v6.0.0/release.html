Before you install
  • Foundry VTT v14 is required. Do not update TOR2E until you have upgraded Foundry.

A rebuilt system, front to back

Version 6.0.0 is the culmination of a complete architectural overhaul. Every actor sheet and every item sheet has been rewritten on Foundry's modern ApplicationV2 engine. The result is a more consistent, more responsive experience — and the foundation all future development will build on.

A world migration runs automatically when you first open your world. It brings all your existing data into the new format. Wait for it to complete before making changes.

✦

What's new

⚔️
Adversary sheet

Complete rebuild. Portrait overlay with attribute level and Might. Progress bars for Endurance and Hate. Four tabs: Combat, Abilities, Description, and War Gear.

🧭
Community sheet

Complete rebuild. Live player presence on member cards. Drag-and-drop travel roles. Active patron tracked and openable from the sheet.

🛡️
Character sheet

Diamond-shaped resource inputs, threshold indicators on Load and Shadow bars, Heroic Stature ribbon, shadow taint tracker, and rest actions in the sidebar.

📜
NPC & Lore sheets

Both fully migrated to ApplicationV2 with the same layout standards as the other actor sheets.

🗡️
All item sheets

Weapons, armour, traits, songs, virtues, rewards, journey logs, undertakings, and more — all rebuilt as ApplicationV2.

🌍
Catalan locale

Partial Catalan (ca) translation added. Contributions to expand coverage are welcome.

✦

Foundry v14 fixes

A large number of issues introduced by Foundry VTT v14 have been resolved in this release:

  • Status condition icons restored on tokens
  • Active Effects Changes tab restored
  • Stance and posture overlays restored after token refreshes
  • Avatar editing compliant with Foundry v14, Tokenizer, and Tokenizer 2
  • Combat targeting comparison corrected
  • Chat messages and roll flags aligned with v14 internals
  • Tabs accessible in read-only sheets (actors and items)
✦

How to upgrade

  1. Back up your world.
  2. Upgrade Foundry VTT to version 14 if you have not already done so.
  3. Install or update TOR2E to v6.0.0 from the package manager.
  4. Launch your world. The migration runs automatically — wait for it to complete before making any changes.
  5. Report issues on the project's GitLab issue tracker.
