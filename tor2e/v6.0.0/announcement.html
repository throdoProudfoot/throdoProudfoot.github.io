v6.0.0 is out

v6.0.0 Foundry VTT 14+

This is the biggest release since TOR2E's first day on Foundry. Every sheet — actors and items — has been completely rebuilt on the modern ApplicationV2 engine.

  • ⚔️
    Brand-new Adversary sheet

    Portrait overlay with attribute level and Might. Progress bars for Endurance and Hate. Four tabs: Combat (fell abilities, editable stats), Abilities, Description, and War Gear.

  • 🧭
    Brand-new Community sheet

    Live player presence on member cards. Drag-and-drop travel roles. Patronage tracked and openable from the sheet. Eye Awareness editable from the Company tab.

  • 🛡️
    Character sheet polished

    Diamond-shaped Endurance/Hope inputs, Load and Shadow threshold indicators, Heroic Stature ribbon, shadow taint tracker, rest actions — all in the sidebar.

  • 📜
    All item sheets rebuilt

    Weapons, armour, traits, songs, virtues, rewards, journey logs, undertakings — every item type is now ApplicationV2.

  • 🐛
    Major Foundry v14 fixes

    Status icons on tokens, Active Effects, stance overlays, avatar editing (Tokenizer compatible), combat targeting — all fixed.

  • 🌍
    Catalan locale (partial)

    Community contributions welcome to expand coverage.

✦
Before you update
  • Foundry VTT v14 is required. Update Foundry before installing TOR2E v6.0.0.
  • Back up your world. A one-way migration runs automatically on first load.

Download via the Foundry VTT package manager. Found a bug? Open an issue on GitLab or drop it in #bug-reports.
